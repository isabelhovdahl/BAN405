# Assignments

Two mandatory assignments. Both must be approved for course approval.

| | Handed out | Due | Form |
|---|---|---|---|
| [Assignment 1](assignment1/) | Week 4 | Week 6 | A Python script (`.py`) |
| [Assignment 2](assignment2/) | Week 9 | Week 11 | A GitHub repository |

Both are submitted on **Canvas**, which is the formal record for course approval.

To pass, you must demonstrate an honest attempt at every task that is not marked optional. If you
cannot complete something, say so in a comment or a markdown cell and explain what went wrong —
that is worth far more than silence.

You must state your use of generative AI in every submission. If you did not use it, state that too.
See `guides/ai-guidelines.md`.

*Assignments will be added here before the course starts.*
