# Assignment 2

**Handed out:** week 9 · **Due:** week 11 · **Submitted as a GitHub repository**

The reproducibility assignment: a complete data analysis project applying everything from weeks 5–9.

Your submission is a GitHub repository containing:

| | |
|---|---|
| `notebook.ipynb` | Your analysis, running top to bottom without errors |
| `data/` | The data needed to run it |
| `environment.yml` | The environment it runs in |
| `.gitignore` | |
| `README.md` | What the project does and how to run it |

Note the layout: the notebook sits at the project root with `data/` **beside** it, so paths are
`data/x.csv` — not `../data/x.csv` as in the lecture notebooks. This is the same structure you will
meet in the exam.

Submit the repository link on Canvas, together with a zip of the project.
