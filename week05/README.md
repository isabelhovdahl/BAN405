# Week 05 — Terminal, git and GitHub

*Interlude: tools of the trade*

This week is a hands-on workshop rather than a notebook. Bring a laptop with git installed.

## Topics

- Navigating your computer from the terminal
- What version control is and why it exists
- The basic git workflow: `init`, `status`, `add`, `commit`, `log`, `diff`
- `.gitignore`
- Connecting a local repository to GitHub: `push`, `pull`, `clone`
