## Topics

- Why virtual environments exist, and why you never install into `base`
- Creating, activating and removing environments with conda
- Exporting an environment to `environment.yml`
- What a project consists of: notebook, `data/`, `environment.yml`, `.gitignore`, README
- Working directory, and the four ways to point at a file: relative, `../` relative, absolute, URL
